# أطلس ليبيا السياحي — نسخة ثابتة تجريبية

هذه نسخة Web GIS مستقلة بلا Backend، مهيأة لتعرض البيانات المخزنة أصلًا في `client/public/data/` من المستودع `tidclibya2026/tidcatlas.ly`.

## طريقة التطبيق

1. أنشئ فرعًا جديدًا من main عبر واجهة GitHub.
2. انسخ ملف `static-atlas/index.html` إلى المسار نفسه في المستودع.
3. انسخ `.github/workflows/deploy-static-webgis.yml` إلى المسار نفسه.
4. راجع ملفات KML الثمانية المعرّفة في الصفحة وتأكد من وجودها. الطبقات المشتقة من الخادم ليست ضمن هذه النسخة.
5. افتح Pull Request للتجربة والمراجعة؛ بعد الدمج وتفعيل GitHub Pages بنمط GitHub Actions نفّذ Workflow يدويًا أو ادفع تغييرًا في الملفات المذكورة.

## قيود مهمة

- لا تدمج قبل تصدير السجلات المحفوظة فقط في قاعدة بيانات tRPC، لأن النسخة الثابتة لا تجلبها.
- هذه واجهة بديلة وظيفية وليس إعادة إنتاج كاملة لتصميم React الأصلي. لا تتضمن إدارة، تسجيل دخول، مساعدًا ذكيًا خادميًا، تسجيلًا صوتيًا، أو طبقات الكثافة والمفضلة المشتقة.
- تعرض نقاط KML وخطوطها ومضلعاتها وGeoJSON؛ يجب اختبار ملفات كل الطبقات الحقيقية وحجمها في المتصفح.
- تحتاج خلفية OpenStreetMap إلى الإنترنت. صور أو روابط عن بعد قد تحتاج إصلاحًا منفصلًا.
- في حالة وجود workflow نشر Pages آخر، عطّله بعد التحقق لمنع تضارب إصدارات النشر.
