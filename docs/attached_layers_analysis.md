## المطابقة الأولية

تعريفات `Home.tsx` الحالية تستخدم أسماء ملفات hashed داخل GitHub Pages (`natural-atlas-with-media_5ccb1fb0.geojson`, `akakus_60c47b41.kml`, `old-tripoli_5c62867b.kml`, `hotels_b9547235.kml`, `resorts_e4a8f065.kml`, `investment_de22d4a0.kml`, `restaurants_0642e048.kml`). الملفات المرفقة هي المصادر الأصلية ذات الأسماء العربية أو الإنجليزية غير hashed، ولذلك يلزم إنشاء أصول تشغيلية مستقرة من الملفات المرفقة، مع الإبقاء على المسارات النسبية الخاصة بـ GitHub Pages.

النسخة `atlasnatrual-with-media.geojson` هي المرشح الأول لطبقة الموارد الطبيعية لأنها تحتوي حقول الوسائط والتوصيل الإعلامي التي لا تظهر في النسخة الأساسية. ملف الفنادق `الفنادق_LY.kml` هو المرشح الأول للطبقة الوطنية، بينما `فنادقفيطرابلس.kml` وقرارات QA تُستخدم للمقارنة والتحقق البصري قبل الاستبدال. لا تُستخدم نسخة الفنادق الموسومة DRAFT كمصدر نهائي دون توثيق ذلك في metadata.

## قاعدة الدمج

سيتم الحفاظ على حقول المصدر والوصف والإحداثيات وبيانات الصور كما هي، مع تطبيع أسماء الملفات فقط لمسارات الويب. لن تُنشأ صور أو أوصاف جديدة من دون مصدر. السجلات التي تفتقد صورة ستبقى بلا صورة أو تستخدم fallback موثقًا موجودًا مسبقًا في `shared/siteImageFallback.ts`.
