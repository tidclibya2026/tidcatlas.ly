# معاينة شاشة الدخول

ظهرت صورة intro المرفوعة أول واجهة عند فتح التطبيق، مع لوحة مؤسسية داكنة تحتوي شعار المشروع، اسم الوزارة والمركز، وصفًا مختصرًا، وزر «دخول إلى الأطلس». على الهاتف انتقل التصميم إلى ترتيب رأسي؛ بقي الغلاف واضحًا والزر ظاهرًا وقابلًا للوصول دون قص في اللوحة.

تم ضبط الحالة الابتدائية في Home بحيث تبدأ `activeLayers` كمصفوفة فارغة، ولا تُحمّل نقاط الطبقات قبل اختيار المستخدم. بعد الضغط على زر الدخول فقط تُعرض واجهة الخريطة ولوحة الطبقات.
