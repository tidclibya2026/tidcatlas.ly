# تحليل تغطية الوسائط المرفقة

أظهر التحليل أن `atlasnatrual-with-media.geojson` يحتوي على 945 معلمًا، لكن 21 سجلًا فقط يحتوي حقول `media_status` و`media_match_type` و`media_match_value` و`images_json`، و14 سجلًا يحتوي حقل `images` غير فارغ. لذلك لا يجوز اعتبار جميع المواقع الطبيعية مزودة بصور مرخصة حتى تصل ملفات الوسائط أو اعتماد رسمي إضافي.

يحتوي `hotels_visual_qa_decisions.json` على 53 قرارًا، وجميعها بحالة `VISUALLY_APPROVED`. هذه القرارات تصلح كمرجع QA للصور المرئية، لكنها لا تثبت وحدها حقوق النشر أو الترخيص ما لم تتضمن metadata الترخيص أو يقدمها المصدر.

النتيجة التشغيلية: تُستخدم بيانات GeoJSON وKML المرفقة كما هي، مع الحفاظ على المصدر وترك السجلات التي لا تملك صورة بلا صورة. لا تُضاف صور خارجية أو أوصاف جديدة دون مصدر وترخيص واضح.
