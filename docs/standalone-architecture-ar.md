# المعمارية المستقلة لأطلس ليبيا السياحي

## الهدف

يحتوي مستودع GitHub على الواجهة الأمامية، والباك اند، ومخطط قاعدة البيانات، وملفات الاختبار، وملفات التشغيل. لا يُفترض أن يكون GitHub نفسه خادمًا للباك اند أو قاعدة البيانات؛ لذلك يحتاج النشر الفعلي إلى خادم Node.js وقاعدة MySQL/MariaDB أو PostgreSQL، مع نطاق مستقل يحدده مالك النظام.

## الوضع الحالي

المشروع الحالي مبني على React وVite وExpress وtRPC وDrizzle وMySQL. توجد نقاط ارتباط بخدمات Manus في المصادقة، وتخزين الملفات، وبعض خدمات Forge والتهيئة التشغيلية. قاعدة البيانات نفسها مبنية على Drizzle/MySQL ويمكن نقلها دون إعادة تصميم شاملة.

## المعمارية المستهدفة

| الطبقة | التنفيذ المستقل المقترح | الملاحظات |
|---|---|---|
| الواجهة | React 19 + Vite + Leaflet | تبقى صفحات الزوار، الإدارة، فريق التوثيق، والمراجعة داخل المستودع |
| الباك اند | Express + tRPC | يبقى عقد API typed، مع استبدال سياق Manus بطبقة جلسات محلية أو مزود OAuth يختاره المركز |
| المصادقة | جلسات JWT محلية أو Keycloak/OIDC | الاختيار الافتراضي الآمن هو حسابات محلية مع كلمات مرور مجزأة وفرض تغيير كلمة مرور المسؤول الأول |
| قاعدة البيانات | MySQL 8 أو MariaDB 11 | المخطط الحالي Drizzle/MySQL، مع migrations قابلة للتشغيل من المستودع |
| الملفات والصور | Volume محلي خارج مجلد build أو S3 متوافق | تُحفظ روابط الملفات وحقوقها في قاعدة البيانات، ولا تُحفظ أسرار التخزين في GitHub |
| الخرائط | Leaflet وبيانات المصادر المرفقة | يحتاج الإنتاج إلى سياسة استخدام مناسبة لمزوّد الخرائط ومصادر البلاطات |
| النشر | GitHub Actions ثم خادم Node أو Docker خارجي | GitHub يحفظ الكود؛ لا يستضيف قاعدة البيانات تلقائيًا |
| النسخ الاحتياطي | mysqldump مجدول إلى مخزن منفصل | لا يوضع backup داخل GitHub إذا احتوى بيانات أو صورًا حقيقية |

## مبدأ الفصل

لن تُحذف البيانات التاريخية أو سجلات التدقيق أثناء التحويل. ستبقى الجداول الحالية ونظام الحالات والمراجعات والصلاحيات، بينما تُستبدل فقط محولات المصادقة والتخزين وخدمات Manus بمكونات محلية أو عامة قابلة للتهيئة.

## قرارات مطلوبة من مالك النظام

يجب اعتماد مزود المصادقة، ومحرك قاعدة البيانات النهائي، وطريقة تخزين الصور قبل تفعيل الإنتاج. يمكن تشغيل النسخة الأولى محليًا باستخدام MySQL/MariaDB وVolume للملفات، ثم نقل التخزين إلى S3 متوافق دون تغيير واجهة الأطلس لأن الباك اند سيستخدم محول تخزين موحدًا.

## حدود GitHub

GitHub مناسب لحفظ جميع الملفات البرمجية وملفات migrations والتوثيق وملفات CI. لكنه ليس بديلًا عن خادم التشغيل أو قاعدة البيانات أو التخزين الدائم. لذلك سيُرفق المستودع بتعليمات تشغيل محلية وملفات CI، ويُترك اختيار الخادم النهائي للمركز.

## سياسة البيانات

لا تُضمّن كلمات المرور، مفاتيح JWT، بيانات اتصال قاعدة البيانات، صورًا غير مرخصة، أو نسخًا احتياطية إنتاجية داخل المستودع. تُحفظ الصور بمصدر ومالك ومصور وترخيص ورابط حقوق، وتبقى السجلات غير المؤكدة في حالة مراجعة بشرية قبل النشر.
