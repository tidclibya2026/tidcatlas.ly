# دليل تشغيل أطلس ليبيا السياحي خارج Manus

## المتطلبات

يحتاج التشغيل إلى Node.js 22 أو أحدث، وpnpm 10، وقاعدة MySQL 8 أو MariaDB 11.4. يمكن تشغيل قاعدة البيانات محليًا أو عبر خدمة مستقلة يملكها المركز. يجب إنشاء ملف `.env` على الخادم اعتمادًا على القالب الموجود في `docs/standalone-env-template.md`.

## التشغيل المحلي

بعد تنزيل المستودع، نفّذ `pnpm install` ثم أنشئ قاعدة البيانات وطبّق migrations عبر `pnpm drizzle-kit migrate`. شغّل الواجهة والباك اند باستخدام `pnpm dev`. المسار العام هو `/public`، وبوابة الإدارة هي `/management`.

## إنشاء مسؤول النظام الأول

بعد تشغيل قاعدة البيانات والباك اند، أرسل طلبًا واحدًا إلى `POST /api/auth/local/bootstrap` يحتوي على `name` و`email` و`password`. يجب تنفيذ ذلك مرة واحدة فقط من شبكة الإدارة، ثم حذف أو تغيير متغيرات bootstrap. بعد الإنشاء يستخدم المسؤول `/management` لتسجيل الدخول وإنشاء حسابات فريق التوثيق وفق الصلاحيات الموجودة في النظام.

## التخزين

يستخدم التشغيل المحلي `STORAGE_DRIVER=local` ويحفظ الملفات داخل `STORAGE_DIR`، وتظهر عبر `PUBLIC_STORAGE_URL`. في الإنتاج يفضل استخدام S3 متوافق أو Volume منفصل مع نسخ احتياطية دورية. لا تُحفظ الصور الكبيرة داخل مجلد Git أو داخل قاعدة البيانات؛ تحفظ قاعدة البيانات بيانات المصدر والحقوق والرابط ومفتاح التخزين فقط.

## التشغيل عبر Docker Compose

يمكن استخدام `docker-compose.standalone.yml` لتشغيل MariaDB والباك اند والتخزين المحلي. قبل التشغيل يجب تغيير كلمات مرور MariaDB و`JWT_SECRET`، ثم تنفيذ `docker compose -f docker-compose.standalone.yml up -d --build`. لا تستخدم القيم الموجودة في الملف كما هي في الإنتاج.

## النشر المستقل

يدفع الكود إلى GitHub، ثم يُبنى على خادم Node أو عبر CI/CD. يجب ضبط متغيرات البيئة في منصة النشر، وتخصيص نطاق HTTPS، وفتح اتصال قاعدة البيانات من الخادم فقط. GitHub يحفظ الكود وملفات migrations ولا يحل محل الخادم أو قاعدة البيانات أو التخزين.

## النسخ الاحتياطي

نفّذ نسخة يومية من قاعدة البيانات باستخدام `mysqldump` إلى تخزين منفصل، واحتفظ بنسخ الصور في Volume أو S3 مع سياسة احتفاظ. اختبر الاستعادة دوريًا في قاعدة منفصلة، ولا ترفع النسخ الاحتياطية الإنتاجية إلى مستودع GitHub.

## ملاحظات أمنية

استخدم HTTPS، وكلمة مرور قوية، ومفتاح JWT عشوائيًا بطول لا يقل عن 32 حرفًا. فعّل حماية الشبكة لقاعدة البيانات، قيّد endpoint bootstrap، راجع صلاحيات المستخدمين، وسجّل قرارات المراجعة والتغييرات في سجل التدقيق. تبقى مصادر الصور وحقوقها حقولًا إلزامية قبل النشر.
